# Nave Cóndor-1 · Viaje por el universo

Simulador espacial en primera persona para niños que empiezan a leer: 18 destinos (Tierra → borde del universo observable), lecturas cortas con voz, y retos de contar, sumar, restar, figuras, patrones y secuencias para "cargar combustible".

## Publicar en GitHub Pages (para instalarla)
1. Crea un repositorio (por ejemplo `nave-condor`) y sube **todos** estos archivos a la raíz.
2. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)`.
3. Abre `https://TU_USUARIO.github.io/nave-condor/` en Chrome o Edge y usa el botón **Instalar** de la barra de direcciones.
4. Después de la primera visita funciona sin internet.

## Controles
- Arrastrar con el mouse o flechas del teclado: mirar alrededor.
- Rueda del mouse o botones Acercar/Alejar: zoom.
- Mapa estelar (arriba a la derecha): volver a destinos abiertos, cambiar el nombre del capitán, reiniciar.

El progreso se guarda en el navegador de cada computador.
